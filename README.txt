WEBSITE ĐỘI HÌNH CHẠM PHAN THIẾT - GITHUB PAGES

1. Tải toàn bộ nội dung trong thư mục này lên repository GitHub.
2. Đảm bảo index.html nằm ngay ở thư mục gốc của repository.
3. Mở assets/script.js và thay DAN_DUONG_DAN_GOOGLE_FORMS_VAO_DAY bằng URL Google Forms.
4. Trên GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
5. Chọn branch main, folder /(root), nhấn Save.
6. Đợi GitHub Pages xuất bản và mở URL được hiển thị trong Settings > Pages.

LƯU Ý:
- Đây là website tĩnh, không chạy PHP/MySQL.
- Không đưa mật khẩu, dữ liệu cá nhân hoặc bảng phản hồi riêng tư lên repository Public.
- Google Forms/Sheets là nơi tiếp nhận và quản lý dữ liệu; chỉ chia sẻ bảng phản hồi cho người được phân quyền.
